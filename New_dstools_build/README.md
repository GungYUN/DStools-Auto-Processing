# Optional DStools SIF recipe

Normal processing uses the already accepted DStools SIF. The new worker checks
actual SIF CLI support before starting scientific work.

The recipe uses placeholder site/source paths. Replace them before
rebuilding; see the guides below. This directory is uploaded separately from
the normal runtime deployment.
